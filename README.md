# Pack de Plugins Vencord par 404sec

Ce pack regroupe l'ensemble des plugins TypeScript personnalisés développés pour Vencord.

## Contenu du pack
1. **`TokenProtector`** : Protection contre les fuites accidentelles de jetons Discord.
2. **`AntiPhishingGuard`** : Détection et alerte sur les liens malveillants/suspicieux.
3. **`PinDmsAndCustomUtils`** : Organisation des messages privés et options d'interface.

## Installation
Copiez les dossiers des plugins souhaités dans le répertoire `src/plugins/` de votre build local Vencord, puis recompilez votre client.
